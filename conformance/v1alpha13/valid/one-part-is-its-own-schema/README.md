# v1alpha13 / valid / one-part-is-its-own-schema

**Regla:** [`01-el-schema` 5](../../../../spec/v1alpha13/01-el-schema.md#5) · **Nivel:** L0 · **Espera:** `accept`

---

Una referencia de una parte es del mismo paquete y el mismo schema: desde `ventas.espana`, `pedidos` es `ventas.espana.pedidos`.
