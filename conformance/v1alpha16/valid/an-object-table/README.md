# v1alpha16 / valid / an-object-table

**Regla:** [`01-object-table.md` §3](../../../../spec/v1alpha16/01-object-table.md#3) · **Espera:** `accept` · **Nivel:** L0

---

El puntero a objetos en su forma mínima: `datasource`, `prefix` tal cual —con el espacio de
`Nueva carpeta`—, `match`, `media` y la cara `D` sobre el listado. No declara columnas: son las
fijas del §1. `retract` con `listing` es legal porque la diferencia de dos listados dice las
bajas.
