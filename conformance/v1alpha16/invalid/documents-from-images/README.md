# v1alpha16 / invalid / documents-from-images

**Regla:** [`02-media-collection.md` §7](../../../../spec/v1alpha16/02-media-collection.md#7) · **Código:** `OOS2040` · **Nivel:** L0

---

El tipo de medio es del documento, y es lo que deja a la colección saber qué puede hacer con lo
que guarda. Una colección de `document` no sale de un conjunto de `image`: se separa por tipo al
catalogar.
