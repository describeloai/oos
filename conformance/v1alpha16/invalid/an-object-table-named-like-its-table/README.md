# v1alpha16 / invalid / an-object-table-named-like-its-table

**Regla:** [`01-object-table.md` §3](../../../../spec/v1alpha16/01-object-table.md#3) · **Código:** `OOS2035` · **Nivel:** L0

---

Un nombre, una cosa (v1alpha14): el `ObjectTable` entra en el espacio de nombres del schema con
la `Table`, la `View`, el `Dataset` y la `MediaCollection`.
