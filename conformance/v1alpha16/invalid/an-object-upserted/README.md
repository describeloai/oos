# v1alpha16 / invalid / an-object-upserted

**Regla:** [`01-object-table.md` §5](../../../../spec/v1alpha16/01-object-table.md#5) · **Código:** `OOS1004` · **Nivel:** L0

---

`upsert` exige una clave; la única de un objeto es `key`, y un objeto cambiado es otra huella
bajo la misma clave: `retract`.
