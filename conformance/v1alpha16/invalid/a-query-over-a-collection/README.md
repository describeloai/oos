# v1alpha16 / invalid / a-query-over-a-collection

**Regla:** [`02-media-collection.md` §2](../../../../spec/v1alpha16/02-media-collection.md#2) · **Código:** `OOS2018` · **Nivel:** L0

Lo que una consulta lee resuelve a una `Table`, una `View`, un `Dataset` o un `ObjectTable`. El
índice de una colección es de la implementación; lo que se quiera de dentro de sus ficheros lo
saca una función a un `Dataset`.
