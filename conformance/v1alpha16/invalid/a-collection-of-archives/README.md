# v1alpha16 / invalid / a-collection-of-archives

**Regla:** [`02-media-collection.md` §7](../../../../spec/v1alpha16/02-media-collection.md#7) · **Código:** `OOS1004` · **Nivel:** L0

---

Una colección sabe lo que guarda: `archive` y `binary` son legales en un `ObjectTable` y no en
una colección. Expandir un zip es una transformación que escribe otro conjunto.
