# v1alpha32 / valid / a-dataset-with-geometry

**Regla:** [`01-la-geometria.md` §1](../../../../spec/v1alpha32/01-la-geometria.md#1) · **Espera:** `accept` · **Nivel:** L0

---

Un dataset declara puntos en su CRS por defecto, polígonos en ETRS89/UTM 30N, cualquier geometría en Web Mercator, líneas geodésicas, las posiciones de una trayectoria como lista y una geometría dentro de un struct (§1, §2, §5).
