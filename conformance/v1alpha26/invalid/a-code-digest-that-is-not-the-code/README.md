# v1alpha26 / invalid / a-code-digest-that-is-not-the-code

`codeDigest` es la huella del código de antes; el fichero devuelve otra cosa con la misma firma. Es el fallo que dejaba una tabla anclada sin recalcular (ORE 0056).
