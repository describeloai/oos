# `scope-annotation-unresolved`

La misma reserva que ya activa `@oosMask`, y el mismo argumento: la anotacion **nombra**
un ambito declarado, no lo declara.

Lo que cambia es la direccion del dano. Una mascara que no resuelve deja un valor sin
enmascarar; un ambito que no resuelve deja la politica autorizando sobre **todas las
filas**, no sobre las del principal. El fallo abre en lugar de cerrar.
