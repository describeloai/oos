# v1alpha18 / invalid / another-librarys-function

**Regla:** [`01-la-funcion-de-codigo.md` §4.1](../../../../spec/v1alpha18/01-la-funcion-de-codigo.md#4.1) · **Espera:** `OOS2013` · **Nivel:** L0

`from otra.biblioteca import function` tapa al de `ore` antes del `def`: `@function` ya no marca una función del árbol, y un documento que la promueve no sale de ningún código.
