# v1alpha18 / valid / keyword-only-and-annotations

**Regla:** [`01-la-funcion-de-codigo.md` §4.1](../../../../spec/v1alpha18/01-la-funcion-de-codigo.md#4.1) · **Nivel:** L0

La firma es la del documento. Las anotaciones (`umbral: float`) no se cotejan como error —el tipo manda el documento, que dice `Decimal`—, el decorador no cuenta, y `*, umbral` es un parámetro más.
