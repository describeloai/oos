# v1alpha18 / valid / the-docstring-optional-and-lists

**Regla:** [`01-la-funcion-de-codigo.md` §4.6](../../../../spec/v1alpha18/01-la-funcion-de-codigo.md#4.6) · **Nivel:** L0

---

La primera línea de la *docstring* es `metadata.description`. `Optional[date]` es `Date` y opcional, aunque no lleve valor por defecto. `list[int]` de vuelta es `output: {type: list<Integer>}`. Y `@ore.function` es el mismo decorador importado de otra forma.
