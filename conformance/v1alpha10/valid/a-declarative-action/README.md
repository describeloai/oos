# v1alpha10 / valid / a-declarative-action

**Regla:** [`02-action.md` 2](../../../../spec/v1alpha10/02-action.md#2) · **Nivel:** L0

---

`segmentar` es lo mas frecuente en una ontologia operacional: «pon `segmento` a lo que me pasan». No hay funcion, no hay runtime, y la carencia la cierra quien la aplica. `actividad` se fija a un valor constante y `segmento` viene de `input.segmento`.
