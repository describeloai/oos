# v1alpha10 / valid / a-function-that-edits-what-it-declares

**Regla:** [`01-function.md` 2](../../../../spec/v1alpha10/01-function.md#2) · **Nivel:** L0

---

`editar` trabaja una fila de `ventas.clientes` y afirma `segmento`. La vista tiene copia (`materialized`), la tabla tiene clave, la propiedad declara su integridad, y `humanApproval` cierra la carencia. Es la funcion de v1alpha2 con la unidad de trabajo declarada.
