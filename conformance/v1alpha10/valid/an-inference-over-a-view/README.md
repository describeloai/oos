# v1alpha10 / valid / an-inference-over-a-view

**Regla:** [`01-function.md` 3](../../../../spec/v1alpha10/01-function.md#3) · **Nivel:** L0

---

`clasificar` lleva cada fila de `ventas.clientes` a `modelo/v2-lite` y lo que vuelve es `segmento`, una propiedad `untrusted`. Es la misma funcion con otro runtime: la salida de un modelo sin endoso vale el minimo del reticulo, y aqui el destino no exige mas.
