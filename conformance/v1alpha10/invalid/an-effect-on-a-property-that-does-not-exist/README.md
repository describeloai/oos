# v1alpha10 / invalid / an-effect-on-a-property-that-does-not-exist

**Regla:** [`01-function.md` 5.4](../../../../spec/v1alpha10/01-function.md#54) · **Nivel:** L0

---

v1alpha2 §8 lo decia y el compilador de referencia no lo hacia: un efecto sobre una propiedad que no existe compilaba. No es una regla nueva: es la de siempre, aplicada. La ontologia no puede afirmar un hecho sobre un campo que no significa nada.
