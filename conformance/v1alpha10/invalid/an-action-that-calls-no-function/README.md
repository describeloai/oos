# v1alpha10 / invalid / an-action-that-calls-no-function

**Regla:** [`02-action.md` 5](../../../../spec/v1alpha10/02-action.md#5) · **Nivel:** L0

---

Una accion con `call` es la puerta de una funcion, y la funcion tiene que estar. Es el mismo codigo que `duties[].call` de un Ruleset, por la misma razon.
