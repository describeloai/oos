# v1alpha12 / invalid / a-dataset-with-both-forms

**Regla:** [`01-dataset.md` 7](../../../../spec/v1alpha12/01-dataset.md#7) · **Nivel:** L0

---

Las dos formas son **la misma cosa con dos procedencias**, y la gramática las distingue por una clave. Un documento que llevara las dos diría que el sistema cumple un plan **y** que código lo escribe, y el mantenedor no sabría de quién es el siguiente snapshot. Es forma (`OOS1004`), no una clave desconocida: las dos claves son de aquí, juntas no.
