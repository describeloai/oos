# v1alpha2 / valid / function-attested-writes

**Regla:** [`02-function.md` §6](../../../../spec/v1alpha2/02-function.md#6) · **Código:** `—` · **Nivel:** L0

---

La funcion lleva `attested`, luego su integridad es la que la atestacion afirma, y el
destino exige `reviewed`. La regla se satisface sin endoso condicional y sin excepciones.

Es el unico caso `accept` del arbol, y hace falta exactamente por eso: una suite compuesta
solo de rechazos no distingue una implementacion estricta de una que rechaza todo.
