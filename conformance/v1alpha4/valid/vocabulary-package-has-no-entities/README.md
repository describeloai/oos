# v1alpha4 / valid / vocabulary-package-has-no-entities

**Regla:** [`01-significado.md` §4.1](../../../../spec/v1alpha4/01-significado.md#41) · **Nivel:** L0

---

Este paquete no tiene entidades. Solo tres conceptos con su clasificacion decidida, para
que otros los importen.

`OOS9004` —*una palabra que nadie habla*— **no se aplica aqui**, y la excepcion no es una
concesion: es el caso que convierte «GDPR como dependencia» en algo literal. Un paquete
regulatorio publica sesenta conceptos y no implementa ninguno; quien lo importa es quien
los habla.

La regla y su excepcion son la misma frase: **un concepto tiene que ser hablado por alguien,
y ese alguien no tiene por que ser quien lo acuno.**
