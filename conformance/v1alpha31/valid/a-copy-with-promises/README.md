# v1alpha31 / valid / a-copy-with-promises

**Regla:** [`01-las-promesas`](../../../../spec/v1alpha31/01-las-promesas.md) · **Nivel:** L0 · **Espera:** `accept`

---

Una copia de una tabla promete volumen, cambio, nulos, ausentes, duplicados y valores válidos (§1–§3): todo con las columnas de su `fields`.
