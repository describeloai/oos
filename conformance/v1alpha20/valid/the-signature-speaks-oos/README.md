# v1alpha20 / valid / the-signature-speaks-oos

**Regla:** [`01-la-firma-habla-oos.md` §1](../../../../spec/v1alpha20/01-la-firma-habla-oos.md#1) · **Espera:** aceptado · **Nivel:** L0

---

Una firma con la hora, lo opaco, el instante con zona, el decimal con su precisión, el dinero y la cantidad con su unidad, una estructura como parámetro y una lista de estructuras como vuelta: todo se deriva, y el documento declara v1alpha20.
