# v1alpha9 / invalid / a-model-without-profile

**Regla:** [`01-model.md` 5](../../../../spec/v1alpha9/01-model.md#5) · **Nivel:** L0

---

Sin `profile` el documento no apunta a ningun numero: no se sabe en que maquina, con que motor ni a cuanto. Un perfil sin numero no existe, y un modelo sin perfil tampoco.
