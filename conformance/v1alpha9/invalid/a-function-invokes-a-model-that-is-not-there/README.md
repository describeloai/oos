# v1alpha9 / invalid / a-function-invokes-a-model-that-is-not-there

**Regla:** [`01-model.md` 4](../../../../spec/v1alpha9/01-model.md#4) · **Nivel:** L0

---

`model: modelo/qwen` esta bien formado y no resuelve: no hay `modelos/qwen.yaml`. Es la misma regla que `backedBy` sobre una vista, con el mismo codigo, porque el remedio es el mismo: escribir el documento que falta o el nombre bueno.
