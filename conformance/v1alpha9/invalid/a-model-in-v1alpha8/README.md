# v1alpha9 / invalid / a-model-in-v1alpha8

**Regla:** [`01-model.md` 5](../../../../spec/v1alpha9/01-model.md#5) · **Nivel:** L0

---

Un `Model` que declara v1alpha8 no es un kind desconocido: es del futuro, y el mensaje tiene que decir de que version es. Es la misma puerta que `Table` en v1alpha7.
