# v1alpha23 / valid / the-signature-speaks-oos-in-typescript

**Regla:** [`01-la-funcion-de-typescript.md` §6.1](../../../../spec/v1alpha23/01-la-funcion-de-typescript.md#6.1) · **Nivel:** L0

---

Un `type` y un `interface` del fichero son `Struct` como parámetro y dentro de una lista; `readonly` no cambia nada; `Date` es un instante (`DateTimeTz`) y las fechas de calendario son `Local…`; `bigint` e `Integer` son `Integer` y `number` es `Float`; `T | null` y `?` son opcionales. Los nombres de `ore` se leen por lo que son: con alias (`Money as Dinero`) y como espacio de nombres (`ore.Decimal`).
