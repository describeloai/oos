# v1alpha23 / valid / a-typescript-function-over-its-parameters

`repeat` no lee la copia ni llama a un modelo: trabaja sobre `text` y `times`. Con `runtime: node`, `input` cuenta para «una función toca algo» (§10). `Integer` es el de `ore`: un `number` que el contrato exige entero; con valor por defecto, el parámetro es opcional.
