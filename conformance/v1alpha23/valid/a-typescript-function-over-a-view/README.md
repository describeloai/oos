`config` es el decorador de Python: un objeto literal (`as const` vale). Con `over`, el primer parámetro es la fila y su anotación no se lee. `async` devuelve `Promise<Riesgo>`, y `Riesgo` es un `interface` del fichero: `output` es el mapa de sus campos, `motivo?` sin `required`. La descripción es la primera línea del JSDoc, sin las etiquetas.
