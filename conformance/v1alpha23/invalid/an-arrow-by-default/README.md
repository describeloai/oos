# v1alpha23 / invalid / an-arrow-by-default

**Regla:** [`01-la-funcion-de-typescript.md` §3](../../../../spec/v1alpha23/01-la-funcion-de-typescript.md#3) · **Espera:** `OOS2043` · **Nivel:** L0

---

Un fichero de `functions/` con `export default` está diciendo «esto es una función», y lo que exporta no es `export default function <nombre>`: no se deriva.
