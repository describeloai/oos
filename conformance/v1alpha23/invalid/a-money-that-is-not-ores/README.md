# v1alpha23 / invalid / a-money-that-is-not-ores

**Regla:** [`01-la-funcion-de-typescript.md` §6.3](../../../../spec/v1alpha23/01-la-funcion-de-typescript.md#6.3) · **Espera:** `OOS2043` · **Nivel:** L0

---

El `Money` de la firma es un alias local de `string`, no el de `ore`: no dice moneda ni precisión que un consumidor pueda creer.
