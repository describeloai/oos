# v1alpha23 / invalid / a-number-is-not-an-integer

**Regla:** [`01-la-funcion-de-typescript.md` §6.2](../../../../spec/v1alpha23/01-la-funcion-de-typescript.md#6.2) · **Espera:** `OOS2013` · **Nivel:** L0

---

Un `number` de JavaScript es un `double`. El documento que dice `Integer` no es el que el código da: para eso se escribe `Integer` (o `bigint`).
