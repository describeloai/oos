# v1alpha23 / invalid / a-document-for-a-file-outside-functions

**Regla:** [`01-la-funcion-de-typescript.md` §9](../../../../spec/v1alpha23/01-la-funcion-de-typescript.md#9) · **Espera:** `OOS2013` · **Nivel:** L0

---

Lo que promueve es la exportación por defecto **en** `functions/`. Fuera de ahí el fichero es un módulo, y un documento que lo nombra no tiene `@function` del que derivarse.
