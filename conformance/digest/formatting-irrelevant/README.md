# digest / formatting-irrelevant

**Regla:** [`90-canonical-form.md` §N7](../../../spec/v1alpha1/90-canonical-form.md) · **Afirmación:** mismo digest

---

Contrapartida a nivel de **digest** de
[`n7-comments-and-formatting`](../../canonical/n7-comments-and-formatting/). Aquel afirma que
las formas canónicas coinciden; este, que el artefacto desplegable es literalmente el mismo.

La diferencia importa en operación: si el formato afectase al digest, pasar el repositorio
por un formateador **obligaría a redesplegar y a volver a firmar** un artefacto idéntico en
significado.
