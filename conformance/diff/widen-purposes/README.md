La política pasa de una finalidad a tres. Mismo principal, mismo recurso, misma obligación.

La **limitación de finalidad** es un principio del RGPD, no una comodidad de diseño: el
dato recogido para revisar compensación no puede usarse para reclutar sin una base
jurídica distinta. Ampliar el conjunto es una decisión legal disfrazada de línea de código.

Y es el eje `POLICY` en su forma más pura: ningún consumidor se rompe, ninguna consulta
falla, ningún dato cambia. **Solo se puede preguntar lo mismo por más motivos.**
