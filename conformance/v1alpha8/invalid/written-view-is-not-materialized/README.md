# Escribir por una vista que no se materializa

El gemelo exacto de `OOS2020` —*lo que no se puede leer se debe materializar*— leído por el otro
lado: **lo que se escribe se debe materializar**.

Una vista virtual es una pregunta que se hace al origen cada vez. No tiene estado, así que no tiene
dónde sostener una edición; y el origen no se toca, porque el puntero es de solo lectura.

*«Por la que la ontología escribe»* no se declara: se deriva. Existe una `Function` con un `effect`
sobre una propiedad de `hr.Employee`, y `hr.Employee` se respalda de `hr.empleados`. El mismo camino
que recorre la lectura.

**Y esto es lo que decide si una vista es espejo o registro**, por vista y no por producto. Sin la
función, esta misma vista compila virtual y refleja el origen exactamente.
