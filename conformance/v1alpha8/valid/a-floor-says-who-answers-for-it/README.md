# valid / a-floor-says-who-answers-for-it

**Regla:** [`04-flow.md` §3.3](../../../spec/v1alpha1/04-flow.md) · **Debe:** aceptar · **Nivel:** L0

---

`erp` declara `gdpr.sensitivity: high` como suelo, y la configuracion declara `owner`.

El suelo de una fuente es la clasificacion **minima** de todo lo que sale de ella, asi que
bajarlo desclasifica en cascada — y a diferencia de subir un techo, no produce ningun
sintoma. De quien lo fija responde alguien, con el mismo vocabulario de handle que
`CODEOWNERS` entiende.
